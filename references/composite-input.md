# 文章内组合图

当用户需要作者卡、互动提示，或将它们与搜一搜组合时，使用 `form: composite-card`。可只选一种，也可选两种或三种。原 `search-strip / end-card / scene-card` 输入继续可用，见 [原搜一搜输入](design-input.md)。

## 设计判断与用户选择

- 用户指定模块时按要求制作；未指定时，根据文章、已有配图与用户资料决定组合，并说明理由。正文已有作者卡时避免再重复介绍；轻量提示通常只需一两个模块。
- 图片比例和像素尺寸由用户选择。先复用任务中已经给出的要求；缺失时提供与当前内容匹配的具体选项，例如 `3:2，1080×720` 与 `2:1，1440×720`，等待选择后再导出。可以接受其他自定义尺寸，不把示例比例当成模板限制。
- 在选定画布内先精简辅助文案、合并重复信息。完整保留作者名、公众号名、指定模块和用户明确要求逐字保留的内容。文案仍放不下时，给出调整尺寸或减少内容的具体选择，等待用户决定。
- 工具负责可重复排版，不理解文案含义，也不自动改写文字。Agent 在填写输入前完成精简与事实核对；只有文章中的收益可以写入文章引导语，作者身份来自用户提供的资料。
- 作者卡资料足够时直接用；缺失的准确姓名、公众号名或指定模块所需素材合并补问。不得把文章中的署名、职业或产品名猜成用户身份。

## 输入

沿用基础字段 `article / article_path`、`analysis`、`placement`、`style`。文章分析中的 `evidence` 必须包含文章实际原文。新增或变化字段：

| 字段 | 规则 |
| --- | --- |
| `form` | 固定为 `composite-card` |
| `modules` | 非空、无重复的数组，值为 `author / search / engagement`。表示选择哪些模块，展示顺序由排版决定 |
| `size` | 必填整数 `width / height`，单位 px；宽 720–2160，高 120–2400。可附 `aspect_ratio: "3:2"`，需与像素尺寸一致（允许四舍五入误差 1 px） |
| `layout` | `auto`（默认）、`stacked` 或 `split`；Agent 可明确选定排版。`split` 需同时选择作者与搜索模块 |
| `copy` | 可选 `headline / benefit`；不需要额外标题时可省略整个字段 |
| `copy_edits` | 可选文案调整记录，例如 `[{"field":"author.description","before":"用户提供的原简介","after":"精简后的简介","reason":"适配选定尺寸"}]`；真实文章及作者资料仅保存在用户输出目录 |
| `author` | 仅在选中 `author` 时提供，支持下方两种来源 |
| `account_name / brand` | 仅在选中 `search` 时提供；准确名称和品牌素材要求与原搜一搜模式相同 |
| `engagement` | 仅在选中 `engagement` 时提供；可以省略以使用默认动作 |

所有输入图片路径都以 JSON 所在目录为基准。风格参考由 Agent 查看并体现在 `analysis.visual_style` 与配色中；不把风格参考自动放入成品。单个作者素材支持 PNG、JPEG、WebP，最多 20 MB。

### 作者资料生成

```json
{
  "author": {
    "mode": "profile",
    "name": "林禾",
    "description": "写下可以试用的小方法。",
    "avatar": {
      "path": "../local-assets/avatar.png",
      "alt": "用户提供的作者头像",
      "basis": "填写用户实际提供的来源与使用依据"
    }
  }
}
```

`name` 必填，`description` 与 `avatar` 可选；没有头像时用文字排版，不自动生成或猜测真人形象。头像采用圆角方形裁切，须检查主体完整。真实姓名与账号名没有默认值。

### 复用现成作者卡

```json
{
  "author": {
    "mode": "image",
    "name": "林禾",
    "image": {
      "path": "../local-assets/author-card.png",
      "alt": "包含林禾姓名及简介的现成作者卡",
      "basis": "填写用户实际提供的来源与使用依据"
    }
  }
}
```

保持整张作者卡的比例、文案和画面，不裁切或重新绘制。图片内已有文字保持位图；SVG 中的外围图形和新文字可编辑，内嵌作者卡不是可拆分文字层。工具检查素材解码和尺寸；Agent 需读图核对作者名、嵌入文字、手机可读性及与整体风格的协调。原卡自带搜索或互动提示时，检查是否与其他模块重复。

### 互动提示

```json
{"engagement":{"actions":["点赞","在看","转发"],"caption":"觉得有帮助，欢迎分享你的体验。"}}
```

默认动作是“点赞 · 在看 · 转发”。`actions` 可自定义 1–12 项，每项最多 24 字，并保留输入顺序；`caption` 可省略。点赞、在看、转发、收藏、留言使用包内原创线条图形，其他动作使用中性圆形标记。这些图形仅用于文章内静态提示，不模仿可点击的微信界面或承诺操作已经执行。

## 排版与错误

上下排版顺序为作者 → 搜索 → 互动；左右分区将作者、搜索并排，互动提示置于下方。标题和可选价值文案在上方。`auto` 会在可容纳内容的候选中，按画布宽高关系选择排版；复用完整作者卡时优先上下排列，减少内嵌文字被缩小。Agent 仍需观察实际成品，必要时显式选择另一种布局。

- `SIZE_REQUIRED`：尚未取得用户的具体尺寸。
- `SIZE_RATIO_MISMATCH`：比例与像素尺寸冲突，需核对用户要求。
- `CANVAS_TOO_SMALL`：在当前文字大小下无法完整容纳所选内容，错误中附候选布局所需的高度；这只是调整建议，不是自动改尺寸的授权。
- 不含搜索模块时不读取品牌素材，也不要求公众号名。含搜索模块时缺少标识返回 `BRAND_REQUIRED`。

PNG 中的可编辑文字在 375 px 手机预览下至少约 12 px；自动检查还核对文字、图片边界和互相遮挡。复用图片中的小字与整体审美需要实际视觉检查。

## 交付与审阅

沿用 PNG、SVG、HTML、375 px 手机预览、设计说明和 manifest。组合图额外记录 `modules / layout / author / engagement / requested_size / copy_edits`；作者图片记录文件名、尺寸、来源和 SHA-256，不记录绝对路径。

在原五项视觉审阅字段之外，再填写：

```json
{"exact_author_name":true,"requested_modules_and_size":true}
```

`exact_author_name` 核对完整作者名（复用卡需读图）；`requested_modules_and_size` 对照本次请求核对模块与像素尺寸。未选择作者或搜索时，相应检查记为 true，并在 `notes` 说明不适用。未经实际观察不能填写通过；演示标识始终保持 `demo_exported`。
