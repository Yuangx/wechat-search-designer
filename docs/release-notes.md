# 0.3.0 · 文章内组合图

本版新增文章内组合图。MIT 许可证继续有效，Skill 标识仍为 `wechat-search-designer`。

## 新增能力

- 作者卡、搜一搜、互动提示可单独使用，也可任意组合为一张图。
- 作者卡支持头像、姓名与简介生成，或复用现成图片；现成卡不裁切、不拆改内部文字。
- 互动默认“点赞 · 在看 · 转发”，支持自定义动作与数量。
- 用户选择比例和像素尺寸；Agent 可建议并等待选择，按选定画布编排内容。
- 自动候选包括上下排列与左右分区。内容超出时先由 Agent 精简辅助文案，完整保留姓名、公众号名和指定模块；仍放不下则请用户调整尺寸或内容。工具不会自行缩小文字、删内容或改变画布。
- 未选择搜索模块时，不要求公众号名或搜一搜标识。

## 使用与验证

可在项目目录运行 `npx skills add Yuangx/wechat-search-designer`，按提示选择 Agent，再依照 README 准备本地导出环境。

运行 `npm run demo:composite -- outputs/composite-demo`，查看三个虚构案例。原有 `npm run demo` 和三种搜一搜输入继续可用。

测试覆盖七种模块组合、明确的像素尺寸、比例冲突、过小画布、长名称与中英文混排、自定义互动、完整作者卡复用、PNG/JPEG/WebP 输入、损坏图片、源文件降级与独立视觉审阅。自动检查不证明 Agent 在所有文章上都能作出合适的设计决策。

新增作者及组合图素材均为原创或虚构示例。包仍不附第三方 PDF、AI 模板、字体或正式搜一搜标识；用户素材的许可条件独立适用。

## 交付边界

输出 PNG、可编辑 SVG、HTML 预览、手机检查图、设计说明和 manifest；复用作者卡中的文字保留为位图。搜索与互动均为静态提示，原文章及发布状态不自动修改。GitHub 检查与正式发布以实际远端记录为准。
