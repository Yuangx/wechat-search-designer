# 0.2.0 · MIT 开源版

面向微信公众号创作者的搜一搜静态物料 Skill。根据文章内容选择简洁搜索条、文末引导卡或主题场景卡，输出 PNG、可编辑 SVG、HTML 预览和设计记录。

本次更新：

- 添加完整 MIT 许可证，原创代码、Skill 指引、文档、组件和示例可在保留声明后复用、修改、分发与商用。
- 同步包配置、Skill 元信息、导出版本、贡献说明与素材授权边界。
- 结构检查核对许可证、版本和分发文件，安装包包含 LICENSE 与 NOTICE。

已有能力：

- 本地品牌输入，公开目录不再附带第三方设计原件与品牌图片。
- 三类虚构文章及明确标记为演示的原创占位标识。
- 损坏图片解码检查、准确的自适应预览说明，以及文件清单打包。
- GitHub 项目说明、贡献与安全说明、Issue / PR 模板和结构验证工作流。

使用前准备 Node.js 22+、Playwright Chromium 和中文字体。真实设计另需提供可用的搜一搜 PNG 标识；演示产物不能替代正式品牌物料。

MIT 授权不包含微信商标、用户上传的内容或第三方素材。公众号文章内适配参考 2021-11-25 版历史设计关系，不代表当前官方投放认证。导出、视觉验收与插入文章分别记录。

安装包与校验记录通过 GitHub Releases 提供；自动检查覆盖 Linux / Node.js 22、24，本地另验证 macOS 导出。其他系统和 Agent 宿主按各自环境验证。
